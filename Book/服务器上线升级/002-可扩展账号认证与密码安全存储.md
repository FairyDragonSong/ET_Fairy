## 背景与目标

升级前 `C2R_Login` 虽然携带账号和密码，但 Realm 不验证密码便签发 Gate Key，任意人知道账号名即可登录。

本项建立真正的认证边界：

- Realm 必须认证成功后才能请求 Gate Key。
- 密码使用带随机盐的 PBKDF2-HMAC-SHA256 哈希存储，数据库不保存明文密码。
- 正式模式默认禁止首次登录自动注册；试用环境可通过显式启动参数开启。
- 登录主流程依赖认证提供方接口，为后续微信小游戏 Code/Token 提供方保留扩展点。

登录限流、防暴力破解属于升级项 003，不在本项重复实现。

## 设计决定

### 认证边界

`AccountAuthentication` 负责按认证提供方分发请求。首个提供方是 `PasswordAccountAuthenticator`；后续微信实现只需新增提供方并扩展协议凭据，不需要绕过或复制 Realm 的 Gate Key 签发流程。

### 账号规范

- 登录名去除首尾空格并转换为小写，长度为 3～32。
- 试用阶段登录名只允许 ASCII 字母、数字和下划线。
- 密码长度为 8～128 个字符。
- 认证失败不向客户端区分“账号不存在”和“密码错误”。

### 密码存储

- 算法：PBKDF2-HMAC-SHA256。
- 随机盐：16 字节。
- 派生结果：32 字节。
- 迭代次数：600000，随账号一起保存，为后续参数升级保留兼容空间。
- 比较使用固定时间比较函数。

参考：[Microsoft `.NET` `Rfc2898DeriveBytes.Pbkdf2` API](https://learn.microsoft.com/dotnet/api/system.security.cryptography.rfc2898derivebytes.pbkdf2?view=net-8.0) 与 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

### 试用注册

新增 `--AccountAutoRegister=0|1`：

- 默认值为 `0`，账号不存在时认证失败。
- 试用环境显式设置为 `1` 后，第一次使用合法账号密码登录会创建账号。
- Watcher 会把该参数转发给子进程；Unity ServerTools 提供对应开关。

该方式只用于第一阶段试用。正式注册、验证码、协议同意和风控将在后续业务接口中独立实现。

## 安全与数据影响

- 新账号只保存密码哈希、随机盐、算法和迭代次数。
- 日志不得记录密码、哈希或盐。
- 当前账号唯一性依靠单 Realm 内账号协程锁；跨 Realm 的数据库唯一索引在升级项 005 完成。在该索引完成前，同一 Zone 不应部署多个可自动注册的 Realm。
- 现有数据库没有账号数据；开启自动注册后将创建新的账号集合。

## 验证结果

- `dotnet build DotNet/DotNet.sln -c Release --no-restore`：0 个警告、0 个错误。
- `dotnet build Unity/Unity.Editor.csproj --no-restore`：0 个错误、12 个既有 LitJson 目标框架警告。
- 通过加载实际编译产物调用 `PasswordHasher`：正确密码验证为 `true`，错误密码为 `false`，相同密码两次生成的盐不同，迭代次数为 600000。
- 已静态检查 Realm：认证失败路径不会请求 Gate Key；成功路径使用规范化账号。
- 已静态检查密码相关日志：没有记录请求密码、密码哈希或盐。
- 本机 MongoDB 27017 端口可用，但本次没有启动完整客户端执行注册、重启后登录和禁用账号的端到端回归；这些场景将在升级项 008 自动化，并建议在进入 003 前人工回归一次。

## 部署与回滚

本项不修改客户端协议字段，但从本版本开始 Realm 会真实校验密码。部署前必须确保 Zone 的 MongoDB 配置可用。

试用环境启动示例：

```powershell
dotnet App.dll --Process=1 --StartConfig=StartConfig/Localhost --Develop=1 --AccountAutoRegister=1
```

正式环境保持 `--AccountAutoRegister=0`。回滚服务端代码不会自动删除已创建账号；账号集合中只有哈希数据，可保留给后续版本。若必须清理试用账号，应先备份并按明确的测试数据库范围操作。
