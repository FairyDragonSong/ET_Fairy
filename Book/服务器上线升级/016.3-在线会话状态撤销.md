# 016.3 在线会话状态撤销

状态：.NET Gate 本机范围已验收，完整 016 仍实施中。

Gate 登录绑定账号 StateVersion；每 5 秒分批查询已登录账号的状态与版本，每批最多 500 个账号。禁用、账号不存在或版本变化时断开相应旧会话，沿用正常下线保存流程。即使账号已重新启用，旧版本连接仍需重新认证。

查询只投影账号名、状态和版本，不读取密码字段。异步查询完成时重新核对捕获的玩家和 Session，不能因旧查询误踢后来登录的连接。单轮检查不重入。

数据库短时不可用时保留在线连接；超过 120 秒未能复核身份后关闭连接（5 秒扫描间隔，Gate 正常调度时约 125 秒内）。这与此前约 95 秒数据库中断演练兼容，不承诺数据库不可用时即时撤销。生产延迟阈值仍需容量实测。

不新增外部协议。Unity 托管服务器不启用此 .NET 专用组件，不能以此声称该部署形态已具备撤销能力。尚未使用的 Gate Key 版本绑定、独立管理入口、主动撤销命令、密码变更与刷新策略仍待完成。

## 兼容性与回滚

新增内存会话字段，不涉及数据库迁移。回滚组件、初始化与定时器及绑定代码即可；回滚后不再具备在线账号版本撤销能力。保留 016.2 的数据库审计和 StateVersion，不删除账号、角色或审计数据。
