# 018.1 账号与会话安全指标

状态：2026-09-12 本机验证通过；告警平台和通知链路未部署。

## 指标口径

新增 11 个进程内计数器，使用 Interlocked 更新与读取，固定名称、无动态标签，并导出 Prometheus counter 类型。所有计数进程重启归零，运维计算应使用 rate/increase 并结合采集可用性，而非直接比较不同进程的绝对值。

| 指标（均以 et_ 开头、_total 结尾） | 计数事件 |
| --- | --- |
| password_change_accepted | 改密返回成功，包括原信封的幂等重试；不是密码实际更新次数 |
| password_change_unconfirmed | 处理抛异常，未向客户端确认成功；含无会话、坏密码/信封、配置/存储故障，不能推断事务未提交 |
| password_change_rate_limited | 账号或全局限流明确拒绝 |
| session_journal_admitted | majority 插入准入记录返回成功，不保证角色绑定或响应送达 |
| session_journal_admission_failures | 准入记录处理异常，登录被拒绝；超时可能仍有记录落库 |
| session_journal_ended | 结束更新实际修改一条记录；幂等空更新不计数 |
| session_journal_end_failures | 结束记录写入抛异常，可能需要后续对账 |
| session_journal_end_skipped | 根场景或数据库已销毁而跳过结束写入；进程退出前不保证被抓取 |
| session_state_revoked | 状态或凭据版本复核不通过导致会话销毁 |
| session_lease_expired | 超过身份复核租约导致会话销毁 |
| session_check_failures | 身份批量复核异常；按失败批处理计数，不是受影响人数 |

指标接口不接收账号名、ID、IP、Token、异常文本等参数。账号维度诊断需经独立授权查询审计，禁止临时将账号追加成指标标签。

## 排障步骤

会话准入失败或结束记录失败增加：先确认采集目标是发生事件的 Gate 进程，查看同时间 `account_session_journal_failed` 的 admission/disconnect 阶段，核查数据库可达性、TLS 证书、运行账号 insert/update 权限及副本集写关注。不要为恢复服务直接授予管理员权限或绕过准入记录门禁。结束失败不意味着角色保存失败，需独立查看角色保存指标和存档证据。

身份复核失败或租约过期增加：核查 MongoDB 连接和身份复核日志，区分正常状态撤销与数据库不可用。不得延长或禁用租约来掩盖故障；恢复数据库后使用正常重新登录验收。

改密未确认/限流增加：先区分配置、存储故障与恶意请求，检查是否同时出现数据库故障。不要打印请求信封排查；遇到不确定提交，用户可使用新密码重新登录确认，或在有效期内按原操作 ID/原信封重试。

候选告警条件：5 分钟内 journal admission/end failures 或 lease expired 有新增应进入调查；改密未确认率需结合最小请求量与实际基线，不能把坏密码等同数据库故障。阈值、持续时间、值班人和通知通道尚未验收，这些是排障入口，不是已部署告警。

## 验证与边界

单测覆盖 1000 次并发递增、固定指标数量、counter 类型、无动态标签及非法枚举拒绝。HTTP 冒烟检查新增指标出现在 `/metrics`。

真实改密测试核对成功 2 次（含幂等）、未确认 4 次、限流 1 次；会话准入 2、结束 2、版本撤销 1。用真实受限 MongoDB 用户触发结束记录更新拒绝，要求失败计数增加。未在本项重跑长时租约过期、强杀或多进程采集测试；不能宣称所有计数器生产路径都已验收。

这是进程内基础指标，不是中央告警平台；RouterManager 不聚合其他进程的计数。生产安全采集、通知到达、恢复告警和告警抑制仍属于完整 018。
