## 问题与方案

业务 Handler 已不记录密码，但框架 `LogMsg` 会对所有收发消息调用 `ToString()`。因此 `C2R_Login`、登录内部消息和 Gate Key 响应仍可能在 Debug 日志中暴露密码、账号或一次性凭据。

- 新增 `ISensitiveMessage` 标记，由消息类型的 partial 声明集中维护，不修改生成代码。
- 密码登录请求、带密码的 Reload 请求、登录响应、Gate 登录请求、Realm/Gate Key 内部请求响应以及客户端内部登录请求全部标记为敏感。
- `LogMsg` 在解析 Opcode 和调用 `ToString()` 前识别敏感类型，只记录消息类型与固定的 `[sensitive payload redacted]`。
- 后续微信 Code、平台 Token、刷新 Token 等协议必须在同一标记文件登记，作为代码评审要求。

## 兼容性

不改变消息 Opcode、序列化格式和客户端协议，仅减少日志内容。日志检索应改用消息类型和业务 `trace_id`，不得依赖认证载荷。
