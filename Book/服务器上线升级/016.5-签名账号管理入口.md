# 016.5 签名账号管理入口

状态：本机签名入口已验收，完整管理治理仍实施中。仅 .NET 本机服务控制台，不新增 HTTP 路由。

操作人的 RSA-PSS/SHA256 签名绑定操作 ID、账号与确认账号 ID、期望版本、数据库/区服、动作、原因码和有效期。服务端只加载公钥授权表，按操作人限制数据库、区服和 enable/disable 动作。RSA 至少 3072 位；命令最多有效 5 分钟，允许签发时钟超前 30 秒。移除公钥或授权到期后，后续调用拒绝。

通过 `ET_ACCOUNT_ADMIN_TRUST_FILE` 指定公钥授权表；未设置时管理功能关闭。授权表必须由部署管理员保护 ACL，不能由普通操作人修改。私钥离线保管，不放入仓库、服务端或日志。持有主机控制权/可修改信任文件的人属于信任边界，签名不能防御被攻陷的主机。

另需设置 `ET_ACCOUNT_ADMIN_DEPLOYMENT_ID`，与授权表和签名命令的 DeploymentId 完全一致。每个部署使用独立标识，防止同名数据库跨环境执行。服务器未就绪或正在停机时拒绝管理操作。

`account-admin <签名文件绝对路径>` 校验后调用 016.2 事务，审计中的操作人来自已验证签名。状态版本递增后 016.3 撤销在线连接，016.4 拒绝旧 Key。重复操作 ID 不重复变更。账号确认字段属于显式目标确认，不是双人审批或 MFA。

尚未完成：操作限流、拒绝操作持久审计、普通运营账号的数据库审计权限隔离、双人审批、生产密钥配置与轮换演练。不要将此入口视为完整管理平台。

## 配置与操作

授权表是 JSON 数组，每条包含 `Id`、`PublicKeyPem`、`DeploymentId`、`Database`、`Zone`、`Actions`（仅 enable/disable）、`ExpiresAt`（Unix 秒）。同一操作人 ID 不能重复，授权文件不允许含私钥。

在独立操作人机器使用 `Tools/ServerOps/New-AccountAdminCommand.ps1`，显式提供私钥文件、操作人、部署、数据库、区服、动作、AccountId、ConfirmAccountId、ExpectedVersion、固定原因码和输出文件。脚本不覆盖已有命令文件；不确定前一次执行结果时重试同一文件/OperationId，不重新签发另一个操作 ID。五分钟后需重新签名，但保持同一操作 ID 和业务参数以查询幂等结果。

在服务器本机控制台执行 `account-admin <签名文件绝对路径>`。APPLIED 表示本次事务提交，ALREADY_APPLIED 表示相同操作已执行，REJECTED 表示未确认执行成功；网络/数据库异常结果不确定时应使用相同操作 ID 重试并核对审计。密钥不通过命令行明文传递，签名文件在有效期内应视为敏感授权凭据。

## 验证与回滚

本机验证入口：`Test-Phase1.ps1`、`Test-AccountAdmin.ps1`。后者创建隔离随机账号和一次性测试密钥，密钥位于 ACL 受限的 `_Env/mongo-local/admin-test-*`，结束时删除本轮私钥；保留签名样本、公钥表与结果，不修改生产信任配置。

撤销入口可移除两个管理环境变量并重启；撤销操作人可从授权表移除该公钥（每次命令重新读取）。回滚代码不删除账号状态版本和审计集合。生产部署前必须补充最小数据库权限和密钥托管，不提供默认生产私钥。
