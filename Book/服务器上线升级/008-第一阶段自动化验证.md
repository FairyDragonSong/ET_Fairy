## 自动化范围

`DotNet.Tests` 是不依赖外部测试包的可执行回归工程，纳入 `DotNet.sln`。当前覆盖：

- 账号规范化、密码长度边界、PBKDF2 随机盐、正确/错误密码和不安全参数。
- Gate Key 一次消费与重放拒绝。
- 单 Session 每秒消息数、字节数限制。
- IP 与账号两个维度的爆破限流和重试时间。
- 角色地图和坐标快照不丢失。
- 停机参与者成功/失败汇总。
- 登录日志、重复登录/重连保护、稳定角色恢复、断线保存确认、MongoDB 唯一索引和停机保存的架构防回退检查。
- RouterManager 存活、就绪、Prometheus 指标和优雅退出运行时冒烟。

统一入口：

```powershell
.\Tools\ServerOps\Test-Phase1.ps1
```

只执行编译和进程内回归时可传 `-SkipRuntimeSmoke`。

## 需要预发布环境执行的场景

当前仓库环境没有 Docker、MongoDB 或 MongoDB Database Tools，无法伪造“已通过”的真实存储与多进程结论。上线前必须在预发布环境补跑并记录：

1. 新账号注册、正确/错误密码登录、Gate Key 重放、IP/账号爆破、单连接消息洪泛。
2. 断线 30 秒内重连、超时重登、同账号重复登录、地图切换后重启恢复。
3. MongoDB 短时不可用时 Map 保留 Unit；恢复后周期保存成功；优雅停机保存失败返回非零退出码。
4. 备份恢复到隔离库，核对 Account/Role 数量、唯一索引、角色地图和坐标并抽查登录。

预发布结果应附执行时间、版本提交、配置名、数据库备份标识和日志位置，敏感凭据不得入库。
