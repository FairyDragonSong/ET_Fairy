# 016.22 恢复数据库受限身份与权限验证

状态：2026-09-12 本机专用集合级受限身份、真实权限与恢复复验通过；生产操作授权和跨机器死亡确认仍未完成。

## 权限与凭据

每次本机恢复演练临时创建独立用户及角色，仅赋予 ET_LOCAL_GAMEPLAY 中：

| 集合 | 动作 |
| --- | --- |
| ET.Server.Account | find |
| ET.Server.AccountSessionJournal | find、update |
| ET.Server.SessionJournalRecoveryAudit | find、insert |

数据库管理凭据仅用于预置审计集合、创建/移除该测试身份及原有测试准备。恢复、事务回滚核验、操作冲突拒绝及幂等重放均使用新 Connect-LocalRecoveryMongo.js 建立的受限连接。

连接固定使用本机测试副本集、TLS/CA、ET_LOCAL_GAMEPLAY 认证库，随机密码仅通过子进程环境传递，不放入命令行、报告或日志；连接异常不输出 URI。身份在替换游戏进程启动后才生成，不额外传给该游戏进程。

finally 清理本次随机前缀用户与角色，并查询确认均不存在；保留会话、中断记录和审计。原有同名环境变量在结束后恢复，不覆盖用户已有环境设置。

## 真实权限验证

使用受限身份执行以下无匹配目标命令，必须明确返回 MongoDB code 13；不将其他错误或空结果当作权限拒绝：

- 修改账号、删除账号；
- 删除会话记录；
- 修改恢复审计、删除恢复审计；
- 读取角色集合。

随后使用相同身份执行实际事务恢复、审计插入、幂等重放和回滚验证，证明允许的路径也能工作，避免只有拒绝测试而正常恢复不可用。

后续 [016.23](016.23-恢复审计权限拒绝与真实事务回滚.md) 已补充审计 insert 权限真实缺失时的完整事务回滚，并在恢复权限后再次通过恢复和同账号隔离复验。

## 边界

这是集合级权限，不是字段级或行级权限。find 账号集合并不由数据库强制隐藏其他字段，update 会话集合也不由数据库强制限定某个 GateInstanceId；调用者必须继续遵守恢复作用域。凭据持有者仍可插入伪造审计，数据库管理员也仍可修改数据，不能将本项称为不可篡改审计系统。

生产还需要操作人认证/签名、作用域授权、密钥管理及审计外部保护；不因本机数据库角色通过就开放生产恢复。工具依然限定同次受控强杀演练，环境上下文不是授权令牌。
