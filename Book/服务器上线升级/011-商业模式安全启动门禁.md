## 目标

示例配置可以方便开发，但不能被误当成商业生产配置。本项让 `Develop=0` 采用失败关闭原则，在 Realm 打开网络入口和执行数据库迁移前验证：

- 生产禁止登录时自动注册账号。
- 密码登录默认关闭；启用时必须由部署方明确确认完整客户端传输链路已加密。
- MongoDB URI 必须由环境变量/Secret Manager 注入，不得使用仓库内连接串。
- MongoDB 必须启用身份认证、有效 TLS，并使用 Replica Set、SRV 集群或负载均衡部署。
- 禁止显式关闭 `retryWrites`。
- 必需 Fiber 初始化异常必须传播到进程启动状态；错误配置以退出码 3 结束，不允许只写日志后挂起。

## 配置方式

开发试用：

```text
--Develop=1 --PasswordLoginEnabled=1 --AccountAutoRegister=1
```

生产密码登录仅在实际完成 WSS/TLS 端到端保护后使用：

```text
--Develop=0 --PasswordLoginEnabled=1 --PasswordLoginTransportSecure=1
```

MongoDB 使用 `ET_MONGO_URI[_ZONE_n]` 和可选的 `ET_MONGO_DATABASE[_ZONE_n]` 注入。安全确认参数不会创建加密；原生 UDP/KCP 当前没有密码传输保护，不得设置为安全。后续微信小游戏应通过 WSS 传递短期平台 Code/Token。

## 兼容性与数据影响

数据库结构不变。未显式开启时，密码认证返回“当前未开放账号密码登录”。旧的本地启动命令需要增加开发模式和密码登录开关；不安全的 Release Realm 会在监听前启动失败，这是预期保护。

## 回滚

移除启动校验、环境变量解析和认证开关即可回滚，但会允许生产误用无认证、无 TLS、单节点 MongoDB 或明文密码链路，不建议线上回滚。
