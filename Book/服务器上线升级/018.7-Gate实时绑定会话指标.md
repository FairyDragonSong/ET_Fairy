# 018.7 Gate 实时绑定会话指标

状态：2026-09-12 本机生命周期与 20 客户端在线数验收通过；完整 018 仍实施中。

## 口径与实现

新增 `et_gate_bound_sessions` gauge，统计该进程中已绑定玩家的 Gate Session。直接在 BindSession 中计入，SessionPlayerComponent 移除/销毁时扣除，不查询数据库会话日志，不包含仅完成 Realm 认证、尚未成功绑定的连接，也不包含 30 秒离线保留的 Player。

组件带绑定计数标记，同一组件重复 TrackBinding 不重复增加，销毁前先清标记再扣除；Awake 重置标记。旧连接替换时组件移除也会扣除，无需等待其角色最终保存或数据库结束记录写入。根场景销毁分支之前处理扣除。

另外导出 `et_gate_session_bindings_total` 与 `et_gate_session_unbindings_total`，表示进程内累计绑定和解绑次数。采用 Interlocked，指标固定名称、无账号/会话 ID 标签。它们不是注册人数、DAU 或跨机器唯一用户数。

在线数是 Gate 绑定会话数，不要求已进入 Map，更不代表单机玩法正在进行。替换会话的同步操作中可能瞬间观察到先增后减的过渡值；多个指标读取并非事务快照，不应逐次要求 gauge 严格等于两个 counter 差值。

## 验收

- 单测对 1000 次并发绑定/解绑操作检查计数和最终 gauge=0，检查 gauge/counter 导出类型。
- 真实 Realm/Gate 改密场景：Realm 成功但未入 Gate 时 0，绑定后 1，版本撤销后 0，新密码登录后 1，正常断开后 0；最终累计绑定/解绑各 2。
- 基线测试在全部客户端连接后与持续 RPC 结束时核对 gauge 等于客户端数量，避免把基线客户端列表长度当成服务端指标证据。

本轮结果：`Test-Phase1.ps1` 编译 0 警告/0 错误、16 项回归及健康/指标/停机和生产门禁通过；`Test-Gameplay.ps1 -SelfCredentials` 新增生命周期断言通过；`-Baseline -Clients 20 -DurationSeconds 10` 服务端 gauge=20，约 10.9 秒窗口内 60 次 RPC、0 错误，正常停机。此窗口没有周期保存，不用它证明持久化吞吐。

证据见本机 `_Env/mongo-local/evidence/gameplay-self-credentials.json`、`gameplay-baseline.json` 和时间戳报告，含父提交与工作区变更标记。没有修改生产在线人数或存档数据。

## 采集与边界

多进程应逐个采集当前存活 Gate 进程并汇总，排除重复采集同一进程与已经离线的旧样本。某个目标 up=0 不等同于其最后一个 gauge 值仍有效。跨 Gate 同账号并发登录的分布式唯一性仍属于 017，不能从本指标推断。

强杀/网络分区、房间重连的计数稳定性、多机汇总和容量阈值尚未在本项验收。20 客户端数值核对不证明 2000/3000 在线容量，2000 同时在线与长时稳定性仍待独立测试。

无数据库字段、索引、客户端协议变化。回滚指标及调用点即可，不改变账号/角色数据；本项不增加常驻服务或通知规则。
