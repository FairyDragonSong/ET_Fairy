# 018 监控告警与容量治理

状态：实施中，未达到上线验收标准。

沿用商业上线后续路线图的完整范围，不以已有 `/metrics` 或新增计数器替代监控平台和告警验收。

## 当前进度

- 已有：进程内登录、HTTP、角色保存计数，进程内存和基础健康状态。
- 018.1：安全事件固定基数计数与排障说明，见 [018.1-账号与会话安全指标](018.1-账号与会话安全指标.md)。
- 待完成：每个独立服务进程的安全采集入口、采集认证/网络隔离、Prometheus 或等价采集部署、集中日志、保留和访问权限。
- 待完成：真实在线数（不能从未结束审计记录推导）、消息延迟分布、邮箱积压、数据库与主机指标。
- 待完成：确定 SLI/SLO、分级告警、接收人、通知通道、抑制与恢复通知，实际故障触发与恢复演练。
- 待完成：2000 在线与 3000 余量测试后制定容量阈值、扩容水位及内存/积压/容量 Runbook。

现有 HTTP `/metrics` 位于 RouterManager，内容只代表该进程。分进程部署不能通过 RouterManager 的零计数推断 Gate 没有故障；集中或逐进程采集未验收前，监控部署仍不完整。
