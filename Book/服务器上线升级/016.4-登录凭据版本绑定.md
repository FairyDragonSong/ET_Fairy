# 016.4 登录凭据版本绑定

状态：本机范围已验收，完整 016 仍实施中。

Realm 认证结果携带账号 StateVersion，经内部 R2G_GetLoginKey 消息送达 Gate。Gate Key 记录账号与认证版本，消费时同时检查 Active 与版本一致。账号封禁再解封后，未使用的旧 Key 也必须拒绝。

登录时间的条件更新同时比较认证时读取的版本，避免认证过程中账号状态变化后继续签发旧身份。旧账号未存储 StateVersion 时按 0 兼容。

Gate 只在登录绑定完成后移除未认证连接超时，失效票据不能通过提前移除超时长期占用连接。

外部客户端协议不变，内部协议增加 AccountStateVersion。Realm/Gate 必须一起升级；本项不声明支持混合版本滚动发布。生成代码和 proto 同步维护，测试 MemoryPack 序列化与对象池字段清理。

验证：待执行未消费 Key 跨封禁/解封拒绝、最新版本 Key 成功、重放拒绝、既有在线撤销及回归测试。
