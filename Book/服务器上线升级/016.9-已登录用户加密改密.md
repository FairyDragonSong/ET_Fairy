# 016.9 已登录用户加密改密

状态：.NET Gate 服务端协议与参考客户端加密实现已通过本机验收（2026-09-12）；客户端产品接入与生产验收待完成，完整 016 仍实施中。

新增 C2G_ChangePassword/G2C_ChangePassword，必须绑定当前登录 Session，验证旧密码和账号版本。旧密码、新密码、账号名、操作 ID、有效期放在同一 AES-256-GCM 载荷中，随机 AES 密钥使用 RSA-OAEP-SHA256 加密，避免将旧密码密文与另一个新密码拼接替换。RSA 至少 4096 位，GCM 标签 16 字节。

客户端必须通过可信配置固定服务端公钥，不能从未认证连接接受替换公钥。复用 ET_ACCOUNT_PASSWORD_PRIVATE_KEY_FILE 解密，缺少私钥时功能关闭。请求整体标记敏感消息，不打印密文或明文。

每账号每分钟最多 5 次、每进程每分钟最多 30 次，计数先于解密与密码校验，跨节点限流待 017。用户只可修改当前账号，成功递增 StateVersion、记录事务审计，旧 Session/Key 失效。网络响应丢失不代表事务失败，保持原操作 ID 和加密信封核对；用户可尝试新密码重新登录。

不提供无需旧密码的自助找回；不包含 Unity 界面和微信端加密接入。公网 TLS/WSS 和可信公钥分发仍需独立验收，消息加密不是部署安全验收的替代品。

## 部署、边界与回滚

使用受保护的 PKCS#8 PEM 私钥文件配置 `ET_ACCOUNT_PASSWORD_PRIVATE_KEY_FILE`，客户端预置信任的对应公钥。协议尾部追加，不改变旧消息编号。无数据库字段迁移；必须具备账号更新与审计插入权限及 MongoDB 事务支持。

账号改密与审计在同一事务提交。自助改密专属的审计写入失败注入、多节点竞争、生产密钥轮换仍未验收；不能用本机成功测试替代这些证据。会话撤销异步生效而非瞬时，数据库不可达仍按既有身份租约处理。当前拒绝请求只有脱敏事件日志，集中告警属于 018。

客户端重试必须保留原操作 ID 与原信封，且在其有效期内；过期后应通过新密码登录确认，不能重新加密并沿用旧操作 ID。托管密码字符串无法保证内存清零，临时字节数组会清零。生产密码登录原有安全门禁未放宽。

回滚代码前先暂停改密入口；已修改的密码、版本和审计不自动回退，不能恢复旧凭据或删除审计。客户端需处理服务器尚不支持该消息的版本窗口。
