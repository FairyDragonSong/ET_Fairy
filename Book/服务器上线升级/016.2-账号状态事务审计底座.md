# 016.2 账号状态事务审计底座

状态：内部底座已通过本机验收。范围为 .NET 内部持久化接口，不是已完成的管理后台。

## 设计与安全边界

Active/Disabled 变更使用 MongoDB 副本集事务，账号状态、单调递增 StateVersion 与审计插入一起提交，采用 Snapshot/Primary/WMajority。操作 ID 使用 GUID 并由审计集合 `_id` 唯一约束；相同命令重试返回已执行，不再次变更；相同 ID 携带不同参数拒绝。过期版本、无变化操作和非法输入拒绝。

审计只保存主体 ID、操作人标识、固定原因码、前后状态、版本与时间，不保存密码、Token、IP 或自由文本。原账号没有 StateVersion 时默认为 0。新增集合 `ET.Server.AccountStateAudit`，不能在回滚时删除该审计集合。

调用者必须先完成独立身份认证、权限检查及操作确认；当前没有生产调用入口，不将传入的 operatorId 当作已认证身份。数据库普通运营角色禁止修改/删除审计的权限配置、外部审计副本、拒绝操作审计、管理限流和在线强退仍待实现。事务不能提供对数据库管理员的不可篡改保证。
