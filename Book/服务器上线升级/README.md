# 服务器上线升级记录

本目录用于记录 ET 服务器从示例环境升级到可上线环境的全部工程变更。每个升级项必须有独立文档，并在本索引登记，确保设计、代码、验证和回滚方式都可以追溯。

## 记录规则

1. 一个可独立验证或回滚的升级项对应一份文档。
2. 文档在实施前创建，实施过程中持续更新，完成验证后才能标记为“已完成”。
3. 每份记录至少包含目标、变更范围、安全考虑、兼容性、验证结果、遗留问题和回滚方式。
4. 账号、密钥、数据库密码等敏感内容不得写入文档或提交到仓库。
5. 只完成代码编译、尚未完成运行时验证的项目，必须明确标记验证边界。
6. 每个升级项完成并通过当前范围验证后，必须创建独立 Git 提交；不得把多个升级项混入同一个提交。
