# 016.26 已登录用户自助软注销

状态：2026-09-13 服务端与本机真实 MongoDB 链路通过；客户端确认界面和生产密钥传输待接入。

## 目标与边界

允许已登录用户主动关闭自己的账号。采用保守规则：验证当前密码和两次完全相同的规范化账号名后立即进入不可重新登录的 `Closed` 终态；保留账号、角色、会话和审计数据，不自动物理删除，也不实现恢复或冷静期。

本项不新增管理端口。客户端通过 Gate 的已认证 Session 提交短时加密信封，服务端仍以 Session 当前绑定账号为授权主体，不能仅凭信封中的账号名操作其他账号。

## 实现

- 新增 `C2G_CloseAccount/G2C_CloseAccount` 协议；请求和响应标记为敏感消息，不进入普通消息正文日志。
- `SelfAccountClosure` 包含 OperationId、账号名、确认账号名、当前密码和最多 5 分钟有效期。
- 复用现有 RSA-4096 + AES-GCM 密钥链，但使用独立关联用途 `ET.AccountClosure.v1`；改密信封与注销信封不能互相解密或替换。
- Gate 要求 Session 仍是 Player 的当前绑定会话，并在 `PlayerSession` 锁内再次核对实例；匿名、旧会话和跨账号请求均拒绝。
- 复用自助凭据操作的全局与逐账号频率限制，不新增无限增长的限流状态。
- MongoDB 事务内完成：读取账号、核对 Active/版本/当前密码、写入 Closed/ClosedAt/新版本、插入 `user-close-account` 状态审计。审计失败或并发冲突时账号更新回滚。
- OperationId 与加密信封摘要绑定；数据库确认后的相同请求返回幂等结果，不能重复推进版本或复用 OperationId 执行不同请求。
- 成功响应发出后延迟 100ms 断开当前 Session；即使该短暂窗口内进程异常，既有会话状态监视器也会根据 Closed/版本变化撤销会话。未消费 Gate Key 和后续 Realm 密码登录均被拒绝。
- 提供固定名称、无动态标签的 accepted/unconfirmed/rate-limited 计数器和处理耗时直方图，拒绝日志不包含账号或信封正文。
- 软注销不清空 DefaultRoleId 或角色数据，为合规导出、客服核对和未来独立物理删除流程保留一致关系。

## 待办与回滚

Unity/微信客户端仍需实现明确的不可逆提示、账号名二次输入和结果展示；生产需验证密钥租约、TLS/WSS、隐私文案和客服处理流程。是否提供冷静期恢复属于产品与合规决策，不在本项中预设。

物理删除必须另建升级项，处理法定保留、不可变审计、备份到期和关联业务数据；不能把本项软注销误称为数据已删除。

回滚会移除自助软注销协议和处理器，不自动恢复已经 Closed 的账号，也不删除其数据或审计。恢复必须使用未来明确授权的独立流程，当前管理 `enable` 动作仍禁止重开 Closed 账号。
